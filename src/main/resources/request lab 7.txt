==========================================================
CÁCH CHẠY (branch asm/lab7)
==========================================================

1) CHẠY ỨNG DỤNG
   cd demob1
   mvnw.cmd spring-boot:run

   Mở trình duyệt:  http://localhost:8081/index.html

   !! Phải vào /index.html, KHÔNG phải http://localhost:8081/
      Vì MyController có @RequestMapping("/") nên "/" trả về trang
      page.html của lab 1-2, không phải ứng dụng Vue.

   Điều hướng 3 trang dùng hash:
      http://localhost:8081/index.html#/categories
      http://localhost:8081/index.html#/products
      http://localhost:8081/index.html#/users

2) DỮ LIỆU
   Không dùng CSDL. Dữ liệu nằm trong bộ nhớ tại
   demob1/src/main/java/com/vn/test/demob1/LAB/repository/
   (dữ liệu mẫu khởi tạo ở constructor của mỗi repository).
   => Thêm/sửa/xóa sẽ MẤT khi khởi động lại ứng dụng.

3) SỬA GIAO DIỆN (Vue)
   Mã nguồn frontend: demob1/lab7-fe  (Vite + Vue 3 SFC + vue-router)

   cd demob1/lab7-fe
   npm install          <- chỉ cần chạy lần đầu (axios & vue đã có sẵn
                           trong package.json, KHÔNG cần npm install axios)
   npm run dev          <- chạy thử ở http://localhost:5173 (hot reload)
   npm run build        <- build ra thư mục dist/

   Sau khi build, copy sang thư mục static của Spring Boot:
      xóa   demob1/src/main/resources/static/assets/
      copy  demob1/lab7-fe/dist/*  ->  demob1/src/main/resources/static/

   Phải xóa assets/ cũ trước vì tên file có mã hash, mỗi lần build ra
   tên khác, không xóa sẽ bị đọng file cũ.

4) CHẠY TEST
   cd demob1
   mvnw.cmd test        <- 12 test

   Lưu ý: "mvnw clean" bị lỗi khi không có mạng (maven-clean-plugin
   thiếu plexus-utils trong ~/.m2). Cần build sạch thì xóa thư mục
   demob1/target/ bằng tay rồi chạy mvnw.cmd test.

5) REST API (cổng 8081)
   GET/POST      /categories        {id, name}
   GET/PUT/DELETE /categories/{id}

   GET/POST      /products          {id, name, price, date, categoryId}
   GET/PUT/DELETE /products/{id}

   GET/POST      /accounts          {username, password, fullname, enabled, role}
   GET/PUT/DELETE /accounts/{username}

   Mã lỗi: 400 dữ liệu không hợp lệ, 404 không tìm thấy,
           409 trùng khóa chính / còn ràng buộc khóa ngoại.
           Thân phản hồi là câu thông báo tiếng Việt.

6) CẤU TRÚC JAVA  (demob1/src/main/java/com/vn/test/demob1/LAB/)
   model/       Category, Product, AppUser   (POJO thuần, không Lombok)
   repository/  lưu dữ liệu trong bộ nhớ
   service/     nghiệp vụ + kiểm tra dữ liệu, ném NotFound/Conflict/
                ValidationException
   controller/  REST controller + ApiExceptionHandler đổi exception
                thành mã HTTP
