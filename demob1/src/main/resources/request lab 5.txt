Lab 5: JWT
Dựa vào bài Lab 6 trong khung chương trình, thực hiện:
- (1đ) GET localhost:8080/jwt-generator -> INPUT: username và password -> OUTPUT: Chuỗi JWT tương ứng
- (1đ) GET localhost:8080/jwt-decoder/{jwt} -> INPUT: Chuỗi JWT -> OUTPUT: Tên tài khoản và ngày hết hạn

- (2đ) POST localhost:8080/login -> Nhận username và password -> Xác thực thông tin đăng nhập hợp lệ thì trả về chuỗi JWT

- (2đ) GET localhost:8080/user -> INPUT: Chuỗi JWT -> Chỉ cho phép tài khoản vai người dùng
- (2đ) GET localhost:8080/admin -> INPUT: Chuỗi JWT -> Chỉ cho phép tài khoản vai quản trị viên

- (2đ) POST localhost:8080/logout -> INPUT: Chuỗi JWT -> Vô hiệu hóa chuỗi JWT, không sử dụng được


======================= CÁCH CHẠY (branch asm/lab5) =======================

cd demob1
mvnw.cmd spring-boot:run          ->  http://localhost:8080

Tài khoản:  user@gmail.com / 123   (USER)
            admin@gmail.com / 123  (ADMIN)
            both@gmail.com / 123   (USER + ADMIN)


======================= POSTMAN =======================

1. GET  http://localhost:8080/jwt-generator?username=user@gmail.com&password=123

2. POST http://localhost:8080/login
        Body -> raw -> JSON:
        {"username":"user@gmail.com","password":"123"}

3. GET  http://localhost:8080/jwt-decoder/<jwt>

4. GET  http://localhost:8080/user
        Header: Authorization: Bearer <jwt>

5. GET  http://localhost:8080/admin
        Header: Authorization: Bearer <jwt>

6. POST http://localhost:8080/logout
        Header: Authorization: Bearer <jwt>
        Không có Body.
        Sau bước này gọi lại (4) bằng đúng <jwt> đó -> 403, không còn thông tin user.

Chạy test:  mvnw.cmd test          -> 19 test
