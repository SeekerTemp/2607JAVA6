===========================================================
1. URI
===========================================================
Trang chat        : http://localhost:8081
H2 console        : http://localhost:8081/h2-console

WebSocket endpoint: /ws
  Bai 1 - chat chung : gui /app/chat        -> nhan /topic/public
  Bai 2 - bao ten    : gui /app/username    -> nhan /topic/public (JOIN + list online)
  Chat rieng         : gui /app/private     -> nhan /topic/private/{u1}--{u2}

REST API:
  POST /api/login                                 dang nhap
  GET  /api/users                                 danh sach tai khoan
  GET  /api/history/private?user1=&user2=         lich su chat rieng

4. XEM LICH SU CHAT BANG H2 DATABASE
===========================================================
QUAN TRONG: app PHAI DANG CHAY thi moi xem duoc.
H2 chay in-memory nen du lieu nam trong RAM cua tien trinh Java,
khong co file .mv.db nao tren dia. Tat app la mat sach.

--- Buoc 1: mo H2 console ---
Vao http://localhost:8081/h2-console

--- Buoc 2: dien form dang nhap roi bam Connect ---
  Saved Settings : Generic H2 (Embedded)
  Driver Class   : org.h2.Driver
  JDBC URL       : jdbc:h2:mem:chatdb      <-- PHAI dung chuoi nay
  User Name      : sa
  Password       : (de trong)

--- Buoc 3: chay cau lenh SQL ---
Man hinh chia 3 khung: trai la cay bang, giua la o go SQL, duoi la ket qua.
Go cau lenh vao o giua roi bam Run (hoac Ctrl + Enter).

Xem toan bo lich su:
  SELECT * FROM CHAT_HISTORY ORDER BY SENT_AT;

Chi xem tin nhan kenh chung:
  SELECT * FROM CHAT_HISTORY WHERE ROOM = 'public' ORDER BY SENT_AT;

Chi xem tin nhan rieng giua u2 va u3:
  SELECT * FROM CHAT_HISTORY WHERE ROOM = 'u2--u3' ORDER BY SENT_AT;

Dem so tin nhan theo tung kenh:
  SELECT ROOM, COUNT(*) AS SO_TIN FROM CHAT_HISTORY GROUP BY ROOM;

Xem gon cho de doc:
  SELECT ROOM, SENDER_NAME, CONTENT, SENT_AT
  FROM CHAT_HISTORY ORDER BY SENT_AT;

Xoa het lich su de demo lai tu dau:
  DELETE FROM CHAT_HISTORY;

--- Y nghia cac cot ---
  ID           khoa chinh, tu tang
  ROOM         kenh chua tin nhan:
                 'public'  = kenh chung
                 'u2--u3'  = kenh rieng giua u2 va u3
                 (ten phong xep theo alphabet nen khong phu thuoc ai gui truoc)
  TYPE         CHAT = tin kenh chung, PRIVATE = tin nhan rieng
  SENDER       username nguoi gui (u2, u3, guest...)
  SENDER_NAME  ten hien thi (Thi No, Chi Pheo...)
  RECIPIENT    username nguoi nhan, chi co gia tri voi tin nhan rieng
  CONTENT      noi dung tin nhan
  SENT_AT      thoi diem gui, dung de sap xep khi nap lai lich su

--- Kiem chung yeu cau cua bai ---
1. H2 luu DAY DU lich su:
   Chat vai cau o kenh chung va kenh rieng -> chay
   SELECT * FROM CHAT_HISTORY; -> thay DU CA HAI loai (ROOM = public va u2--u3).

2. Kenh chung chi doc tin moi tu luc vao phong:
   Du DB co day tin cu, panel vao sau van khong thay chung -> vi client
   khong goi API nao de tai lich su kenh chung (co tinh khong lam).

3. Tat di bat lai thi reset:
   Tat app -> chay lai -> mo H2 console -> SELECT * FROM CHAT_HISTORY;
   -> bang TRONG (0 rows).

===========================================================
5. LOI THUONG GAP
===========================================================
"Port 8081 was already in use"
  Con mot lan chay cu chua tat. Xem PID va tat:
    netstat -ano | findstr :8081
    taskkill /PID <pid> /F
  Hoac doi port:
    mvnw.cmd spring-boot:run -Dspring-boot.run.arguments=--server.port=8090

Bam Connect nhung den bao van do
  Trang nap Vue / SockJS / StompJs tu CDN nen may phai co mang.

H2 console bao sai JDBC URL
  Phai dien dung jdbc:h2:mem:chatdb, user sa, password de trong.

Chat rieng khong nap lai lich su
  Lich su chi nap khi bam Connect. Neu da tat server thi du lieu da reset,
  dung nhu yeu cau cua bai (H2 in-memory).

Sua code xong chay lai van thay giao dien cu
  Trinh duyet cache -> bam Ctrl + F5.
